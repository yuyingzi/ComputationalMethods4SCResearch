# Deep Reinforcement Learning Course

Working code and output-free notebooks from the
[Hugging Face Deep RL Course](https://huggingface.co/learn/deep-rl-course/en/unit0/introduction).
Trained models and large run artifacts are published separately on the Hugging Face Hub.

| 3 | DQN and Atari | [`notebooks/unit3/unit3.ipynb`](notebooks/unit3/unit3.ipynb) |
| 4 | REINFORCE | [`scripts/unit4/`](scripts/unit4/) |
| 5 | ML-Agents and Unity environments | [`notebooks/unit5/unit5.ipynb`](notebooks/unit5/unit5.ipynb) |
| Bonus 1 | Huggy with ML-Agents | [`notebooks/bonus-unit1/bonus-unit1.ipynb`](notebooks/bonus-unit1/bonus-unit1.ipynb) |

Unit 3 contains the completed DQN command and Hub target. Unit 5 includes a
Colab-compatible Python 3.10 setup for the older ML-Agents dependency range.
